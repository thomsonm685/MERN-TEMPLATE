Get Claude Code onto your computer

Claude Code is the assistant that does the building. Download the app from claude.com/claude-code, install it like any other program, and sign in with your Claude account.

Open the Code tab and start a new session. It'll ask which folder to work in — make a new empty one somewhere you'll remember, like a folder called Apps in your Documents. You'll get a chat box. That's where everything from here happens.

Keep it local. If the app offers to run your session in the cloud, say no for this. A cloud session runs on Anthropic's computers, not yours — your app wouldn't open on your own machine.

Claude Code is the assistant that does the building. In the terminal it lives in a plain text window where you type instead of click. It looks intimidating and isn't; you'll only ever type whole sentences into it.

Install it from claude.com/claude-code, then open the Terminal app (Mac: press ⌘ Space, type "Terminal", hit Enter — Windows: search for "Terminal" in the Start menu) and type:

Type this, then press Enter 
claude

You'll be asked to sign in with your Claude account. Once you see a prompt waiting for you, you're in — and every step from here happens in this same window.

Connect the Grimoire library

Grimoire is a shared shelf of tools our team has built for Claude. Connecting to it is a one-off — you never do this again.

Type this into the chat box, exactly as it reads, and press Enter:

Type this into the chat box 
Add the Grimoire plugin marketplace to my Claude settings — it's the GitHub repo odyssey-core/grimoire

Claude will edit its own settings file and tell you when it's done. It may ask permission to change the file — say yes. Then quit the app and open it again so it picks up the new library.

Type this, then press Enter 
/plugin marketplace add odyssey-core/grimoire

The / at the start matters. Claude will confirm the library is connected.

Install the app builder

Now take the tool that builds apps off the shelf.

Click the + button next to the chat box, choose Plugins, then Add plugin. Find app-builder in the list and install it. When it asks where, choose user — that makes it available everywhere on your computer, not just in this one folder.

If you'd rather not hunt through menus, just ask instead:

Type this into the chat box 
Install the app-builder plugin from grimoire, for my whole user account
Type this, then press Enter 
/plugin install app-builder@grimoire

You'll be asked where to install it. Choose user — that makes it available everywhere on your computer, not just in one folder.

That's the setup done. Steps 1–3 are once and for all. Every future app starts at step 4.

Start your first app

With Claude Code open, tell itWith Claude Code open in your terminal, tell it what you're doing, in your own words:

Type this, then press Enter 
build me an app

or, if you prefer the exact command:
/app-builder:new-app

Claude will ask you what to call it, then walk you through about eight questions. They're all plain English, and none of them are about technology:

  • What does your app do, and what problem does it solve?
  • Who's going to use it? Picture one specific person.
  • When someone opens it on a normal day, what did they come to do?
  • Do people sign in with their own account?
  • What are the main things it needs to remember?
  • How should it look — and is there a colour you want it built around?

Answer honestly and roughly — "I don't know yet" is a fine answer, and Claude will pick something sensible. When it's got enough, it reads your plan back to you in plain English and waits for you to say go.

Then it builds. Somewhere between fifteen and thirty-five minutes later, you'll get a web address like http://localhost:5173. Paste it into your browser, make yourself an account, and there's your app.

Now just talk to it

This is the part people don't quite believe until they try it. Your app isn't finished — it's started. To change anything, describe the change the way you'd describe it to a person sitting next to you:

  • Add a notes box to each entry
  • Make the buttons green instead of blue
  • I want to see how many I did this week at the top
  • Let me upload a photo with each one
  • The sign-up page is confusing — simplify it

Claude makes the change, checks the app still works, and tells you what to refresh. You never need to learn what any of it is called.

If something doesn't go to plan

It says app-builder can't be found
The library list hasn't refreshed. Quit the app, open it again, and try step 3 once more. Still nothing? Ask Claude: "check whether the grimoire marketplace is in my settings." Type /plugin marketplace update, pick grimoire, choose "Update marketplace", then try step 3 again.
It asks you to install something first
Most likely Node, a free piece of software the app runs on. Claude will give you the link and wait. Download the big green LTS button, run the installer, then restart Claude Code and say "I've installed it".
The web address shows a wall of text instead of your app
You've opened the wrong one. The app is the address ending in 5173, not 3000. Ask Claude "what's my app's address again?"
The address won't open at all
Check you're in a local session rather than a cloud one. Cloud sessions run on Anthropic's computers, so localhost points at a machine that isn't yours. Start a fresh local session and ask Claude to start your app again.
Something looks broken and you don't know why
Say so, in exactly those words. "Something looks broken" is a perfectly good bug report — Claude can read the errors itself, and you don't have to.
You closed everything and want your app back
Open Claude Code, start a session in your app's folder, and say "start my app". Open your terminal, type cd then a space, drag your app's folder onto the window, press Enter, type claude, and then say "start my app".
